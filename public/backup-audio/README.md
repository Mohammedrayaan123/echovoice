# Optional backup clips

This folder has no bundled voice recordings. To prepare a demo using your own
voice, create a profile in EchoVoice, generate three short reference clips, and
save the downloads here as `clip1.mp3`, `clip2.mp3`, and `clip3.mp3`.

Use only recordings you have permission to clone. The app shows the backup
control only when these files exist. Backup clips are fixed audio and do not
reflect changes to the script or voice settings.
